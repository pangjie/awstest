# 综合统计

入口：工时体系 → 综合统计。管理员自动拥有权限；其他账号须单独授权“综合统计”。统计明细接口需要登录，不属于公开波次下载 API。

## 使用

选择起止日期，点击查询。日期按美东自然日，最多三个自然月，结束日期最晚为今天。默认选中上月；也可快捷选择今天、昨天、上周或本月至今天。不会自动轮询。

每次查询由服务器在首次读取时固定截止时间，后续分页沿用同一时间和数据版本。页面不单独展示截止时间，Excel 的“导出信息”以 UTC Z 记录该时刻。包含今天时标注“当日快照，时效暂估”；数字保持不变，再次点击查询才更新。

1. 项目与类型汇总：总体信息、项目工时、爆品/单件/多件/混件的三种时效。项目依次为波次拣货、单件扫描、混件扫描、问题单、仓务、清洁、在岗待命；额外历史项目保留在待命之前。总体数字合并为一行；项目工时和波次类型汇总不分页，波次类型表按页面宽度排布。
2. 员工汇总：姓名、出勤天数、各项目用时、待命、工作合计及工作时间占比。不显示个人折算件数、时效、组织、完成波次数、异常数或在岗合计。保留列排序，仅显示有记录的员工；点击姓名查看每日汇总。停用但期间有记录的员工保留。
3. 详细记录：仅显示在员工汇总中选中的员工、当前查询时段内的每日汇总。不再提供筛选控件或明细类型切换；未选择员工时提示先点击姓名。Excel 汇集查询时段内所有有记录员工的每日汇总。

日期、快捷选择、查询和导出位于标题栏。导出完整 Excel 不受页面筛选影响，按页面顺序包含总体统计（统计项、数值两列，纵向排列）、项目工时、波次类型汇总、员工汇总、每日汇总五张统计表，以及简短的导出信息表。有异常时另附异常记录表；不再导出个人波次明细、时间片段或长篇统计口径。员工 ID 不显示、不导出。时刻使用 UTC Z；明细时刻和用时显示到分钟，用时保留精确的可求和 Excel 数值，使用 [h]:mm 格式。

## 计算口径

- 项目日均用时＝项目总用时÷查询期实际工作日数（有有效考勤的日期）。参与人次按“员工＋日期＋项目”去重，同一天暂停、恢复或多次参与同一项目仍计一次；人均用时＝项目总用时÷参与人次。工时占比＝项目总用时÷全部在岗时长。无有效工作日或无人参与时，相应均值显示零。
- 员工汇总和员工每日汇总完整展开，不分页、不设置表格内部滚动区；长表随整个页面滚动。

- 任务用时取计时片段与考勤区间交集；暂停后恢复的各片段累加，不计午休。
- 当天尚未结束的考勤，以及该开放考勤内仍在进行的任务，暂计到查询截止时刻。未来开始的记录不计；历史未结束记录不延长到今天。统计只读，不写入结束时间、不完结任务。
- 在岗待命为考勤内无任务覆盖的区间，并非主动分配的任务。
- 完成产量按当天创建且当天完结的波次去重汇总；订单数是波次存储数值之和，并非按订单号去重。
- 今日未完结波次计入项目工时，不计入完成件数和类型拣货时效的分子、分母；类型拣货时效仅使用截止时间前已完结波次的件数和工时。正常进行中的今日波次不作为历史异常。
- 总体拣货效率＝完成波次件数÷全部员工在岗人工小时（含待命），无在岗时长时显示空值。个人页面与导出不展示折算件数或个人时效，不按个人核算扫描时效。
- 单件/混件拣货时效＝对应完成波次件数÷对应波次工时；扫描时效＝同一件数÷对应固定扫描工时；综合时效＝同一件数÷两种工时之和。
- 爆品、多件不分配扫描工时，综合时效等于拣货时效。
- 扫描数据未绑定具体波次，也没有实扫件数。以上扫描时效是同期折算，跨日扫描可能不匹配。
- 人工小时是参与员工用时之和。工作日由有效考勤日期去重，出勤人天由员工和日期去重，不排除周末。

## 异常与限制

历史未结束、无效或重叠的记录会显示异常，不使用当前时间补齐。重叠任务不任意分配给某个项目；未知任务区间不伪装为待命。存在异常时，工时是可确认记录的部分统计，不能直接当作完整考勤或绩效结论。当日扫描时效和综合时效使用同期完成产量折算，扫描与波次完结可能不同步，仅为暂估。

缺少拣货工时或扫描工时的相应时效显示为空/待核对，不能显示无穷大。过去自动收尾未保存独立标记，仍按现有时间值计算，无法事后可靠还原实际下班时间。

后端按七天一批读取原始记录，使用只读事务；若分页期间工时数据发生变更，停止并要求重新查询，避免混合不同版本。最多读取 50,000 个计时片段、考勤或任务；超过范围会明确提示缩短查询，不静默截断。前端 Worker 负责统计，浏览器负责 Excel 生成；不新增汇总表，不修改历史，不新增 AWS 服务。
